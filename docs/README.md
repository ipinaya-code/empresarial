## Documentos originales

En `entregables/PRACTICA EMPRESARIAL/` se conservan cuatro matrices. `GRUPO_2_FIREFOX_MATRIZ_SEGUIMIENTO.xlsm`, hoja 1, identifica: bloqueo transaccional; refactorización de disponibilidad; caché; protocolo de estrés. Las otras versiones contienen diferencias de fechas y propuestas de ampliación. No se sobrescriben evidencias académicas originales.

Precedencia: objetivos originales → requisitos de este repositorio → decisiones técnicas → resultados medidos. Toda ampliación o cambio de fecha se registra explícitamente y requiere la revisión académica correspondiente. “Implementado”, “medido” y “aceptado por el docente” son estados diferentes.
